# VitalLink - Connect. Heal. Thrive.

A modern, responsive healthcare platform website that bridges the gap between patients, healthcare providers, and wellness resources.

## 🌟 Overview

VitalLink is a digital health platform designed to make healthcare more accessible, connected, and empowering. The website provides a comprehensive interface for patients to access telehealth services, wellness resources, and community support, while offering healthcare providers tools for collaboration and patient management.

## ✨ Features

- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Interactive Animations**: Smooth scroll animations and transitions using JavaScript and AOS library
- **Print-Optimized**: Special CSS styling for clean PDF export of pages

## 🚀 Pages

1. **Home** (`index.html`)
   - Hero section with platform statistics
   - Mission statement
   - Featured services overview
   - Platform exploration cards

2. **About** (`about.html`)
   - Company mission and values
   - Platform goals
   - How VitalLink works (4-step process)

3. **Services** (`services.html`)
   - 6 health service offerings with pricing
   - Patient-focused services
   - Provider collaboration tools
   - Resource library

4. **Knowledge Hub** (`knowledgehub.html`)
   - Featured health topics
   - Wellness articles and guides
   - Community wellness stories
   - Platform vision statement

5. **Contact** (`contact.html`)
   - Contact form with multiple inquiry types
   - Contact information and business hours
   - Social media links
   - Interactive Google Maps location

## 🛠️ Technologies Used

- **HTML**: Semantic markup structure
- **CSS**: Custom styling with modern features
  - CSS Grid & Flexbox for layouts
  - CSS Animations & Transitions
  - Media queries for responsive design
  - Print-specific styles for PDF export
- **JavaScript**: Interactive features and animations
- **Font Awesome 6.0**: Icon library
- **Google Fonts**: Poppins and Roboto typefaces

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/vitalink.git
   ```

2. Navigate to the project directory:
   ```bash
   cd vitalink
   ```

3. Open `index.html` in your web browser or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   ```

4. Visit `http://localhost:8000` in your browser
